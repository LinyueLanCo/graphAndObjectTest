# 基础 C++ 游戏方向练习测试

这是一个简单的个人学习向 C++ 2D 项目。

项目目前主要基于 **EasyX** 进行图形绘制，算是我从控制台小游戏逐渐过渡到窗口图形程序时的练习项目。

目前它还不是一个完整游戏，更像是一个用来练习各种“游戏底层概念”的小框架。

目前进度：**30% 左右（大概）**

---

## 目前能做到的内容

目前已经实现或者正在测试的东西包括：

- 抽象出基础的 Entity / Player 概念
- 基于 EasyX 绘制图片
- 支持 PNG 透明图片绘制
- 支持简单的 Sprite 封装
- 支持图片的缩放与偏移
- 支持基础的世界坐标到屏幕坐标转换
- 支持碰撞箱
- 支持矩形碰撞检测
- 支持贴边不算碰撞的重叠检测
- 支持基础状态切换
- 支持基于简单物理的角色移动
- 支持重力、跳跃、落地检测
- 支持持续接收输入
- 支持方向键移动
- 支持 Shift 冲刺
- 支持 Space 跳跃
- 支持输出角色状态变化，例如：
  - 碰撞状态
  - 落地状态
  - 起跳 / 在空中状态
  - 冲刺状态
- 支持背景图绘制
- 使用批量绘制减少画面闪烁

这个项目目前还比较早期，很多东西还写在一起。

## 资源文件说明

当前代码中会读取一些图片资源，例如：

- `background.jpg`
- `player1.png`
- `player2.png`
- `player3.png`

## 为什么做这个项目

之前我主要写的是控制台小游戏，比如：

- 简单 RPG
- 俄罗斯方块
- 贪吃蛇
- 炸弹人思路测试

这些项目让我理解了很多基础逻辑，比如：

- 主循环
- 输入
- 渲染
- 碰撞
- 状态变化
- 地图数组
- 简单 AI / 寻路思路

这个 EasyX 项目算是我从控制台输出过渡到真正图形窗口的一步。

现在的目标不是马上做出完整游戏，而是慢慢把这些游戏开发里的基础模块拆出来，逐渐理解一个简单 2D 游戏框架应该怎么组织。
